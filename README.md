# 📞 Análise de Chamadas por Região

Projeto de análise e visualização de dados desenvolvido com Python e Plotly.

## 🎯 Objetivo

Analisar o volume de chamadas ao longo dos meses (de Maio a Novembro), comparando as regiões e identificando a evolução do tráfego.

## 🛠️ Tecnologias

- Python
- Plotly
- Visual Studio Code
